# Театральный мир

**Театральный мир** — многостраничный информационный сайт, посвящённый театру, спектаклям и актёрам.

Проект помогает пользователям знакомиться с театральными постановками, выбирать спектакли по жанрам и настроению, узнавать об актёрах и сохранять понравившиеся постановки.

## Ссылка на сайт

[Открыть «Театральный мир»](https://lopouhina.github.io/theatrical-world_site/)

## Возможности сайта

- **Главная страница** — популярные спектакли и театральные жанры.
- **Каталог спектаклей** — просмотр постановок и фильтрация по жанрам.
- **Страница спектакля** — подробная информация о постановке и отзывы.
- **Актёры** — список актёров и отдельные страницы с информацией о них.
- **Избранное** — добавление и удаление понравившихся спектаклей.
- **Подбор спектакля** — случайный выбор постановки и рекомендации по настроению.
- **О проекте** — информация о сайте и его возможностях.

## Используемые технологии

- **HTML5** — структура страниц.
- **CSS3** — оформление интерфейса.
- **Bootstrap 5** — адаптивная сетка, карточки, кнопки и навигация.
- **JavaScript** — интерактивность, фильтрация, подбор спектаклей и избранное.
- **LocalStorage** — хранение пользовательских данных в браузере.
- **Git и GitHub** — контроль версий.
- **GitHub Pages** — публикация сайта.

## Запуск проекта

1. Скачайте репозиторий или клонируйте его:

   `git clone https://github.com/Lopouhina/theatrical-world_site.git`

2. Откройте папку проекта в Visual Studio Code.
3. Запустите `index.html` в браузере или через расширение Live Server.

Для просмотра опубликованной версии установка дополнительных программ не требуется.

## Особенности проекта

- Адаптивный интерфейс для разных размеров экрана.
- Единая навигация между страницами.
- Интерактивные элементы и карточки спектаклей.
- Сохранение избранного в браузере.
- Подбор театральных постановок по жанрам и настроению.

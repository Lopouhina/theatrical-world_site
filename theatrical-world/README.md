
# Театральный мир

«Театральный мир» — учебный веб-сайт, посвящённый театральным постановкам. Проект позволяет знакомиться со спектаклями, изучать жанры, сохранять понравившиеся постановки, оставлять отзывы и получать рекомендации.

## Возможности сайта

- Просмотр главной страницы с информацией о проекте.
- Каталог театральных спектаклей.
- Фильтрация и сортировка спектаклей.
- Просмотр подробной информации о постановках.
- Знакомство с театральными жанрами.
- Раздел, посвящённый актёрам.
- Добавление спектаклей в избранное.
- Сохранение избранного в браузере.
- Публикация и удаление отзывов.
- Оценка спектаклей по пятибалльной шкале.
- Отображение отзывов на страницах спектаклей.
- Генератор случайного спектакля.
- Подбор спектакля по настроению пользователя.

## Используемые технологии

- HTML5 — структура веб-страниц.
- CSS3 — оформление и адаптивная вёрстка.
- JavaScript — интерактивные возможности сайта.
- LocalStorage — хранение избранного и отзывов в браузере.
- Git — контроль версий.
- GitHub — хранение исходного кода.
- GitHub Pages — публикация сайта.

## Основные разделы

### Главная страница

Знакомит пользователя с сайтом и предоставляет переходы к основным разделам.

### Каталог спектаклей

Содержит карточки театральных постановок с афишами и краткой информацией. Пользователь может использовать фильтрацию и сортировку.

### Страница спектакля

Отображает название, жанр, описание, продолжительность, возрастное ограничение и другую информацию о постановке. Также доступны отзывы зрителей.

### Избранное

Позволяет сохранять понравившиеся спектакли. Данные сохраняются в LocalStorage и остаются доступными после обновления страницы.

### Отзывы

Пользователь может выбрать спектакль, поставить оценку, написать отзыв и удалить его. Отзывы отображаются на соответствующих страницах спектаклей.

### Подбор спектакля

Включает два инструмента:

1. Генератор случайного спектакля.
2. Подбор постановки в зависимости от настроения пользователя.


## Хранение данных

Избранные спектакли и отзывы сохраняются в LocalStorage браузера.

Данные доступны только в том браузере и на том сайте, где они были созданы. Проект не использует серверную базу данных и регистрацию пользователей.
